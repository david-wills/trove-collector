Trove Browser Watcher

The watcher itself never reads page content — it only sees tab URLs and titles, and everything stays on this machine. Page observation below is a separate, off-by-default collector that does read pages, gated by Chrome's own permission prompt.

Allows the extension to see page content on all sites. Off: the extension cannot read any page. Chrome's per-site controls (chrome://extensions → details → site access) still apply on top — e.g. exclude specific sites entirely.

Records which ads are shown to you (network, advertiser, landing link) and how long each was on screen. Never blocks ads, never captures page text.
